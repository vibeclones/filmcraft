# filmcraft (Vibeclones mirror)

Hosted copies of the browser (WebAssembly) builds of [filmcraft](https://github.com/storytold/filmcraft), a Premiere-style video editor by ArtCraft. This repo only mirrors upstream release zips; the code is theirs.

- Latest: `/filmcraft/latest/`
- Specific version: `/filmcraft/v<version>/`
- Version list: `/filmcraft/versions.json`

Each version folder is the unmodified contents of upstream's `filmcraft-web-<version>.zip` release asset, including its license files. Upstream license: Apache-2.0. A scheduled workflow mirrors new releases.
